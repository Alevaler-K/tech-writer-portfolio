# Быстрый старт: Интеграция с API интернет-магазина

Добро пожаловать в документацию API нашего сервиса! Это руководство поможет вам сделать первый запрос к системе за 5 минут.

## 1. Авторизация
Все запросы к защищенным эндпоинтам требуют передачи JWT-токена в заголовке `Authorization`.

Пример запроса с токеном:
```bash
curl -X GET "https://api.mystore.ru/v1/cart" \
  -H "Authorization: Bearer <ваш_токен>"
