# Релиз v1.2.0 — Обновление логистики и чекаута

**Дата релиза:** 15 ноября 2026  
**Статус:** Развернуто на Production  

В этом релизе мы улучшили процесс оформления заказов и добавили новые возможности для интеграции со службами доставки.

---

## 🚀 Главные изменения (New Features)

* **Расчет доставки по регионам:** В метод создания заказа (`POST /orders`) добавлена логика расчета стоимости с учетом удаленности склада.
* **Обновление статусов заказа:** В жизненный цикл заказа добавлен новый промежуточный статус `ASSEMBLING` (сборка на складе). Обновлена соответствующая схема в [OpenAPI спецификации](../api/openapi.yaml).

---

## 🐛 Исправления ошибок (Bug Fixes)
* Исправлен баг, при котором после успешной оплаты корзина пользователя иногда не очищалась автоматически.
* Снижен уровень ложных срабатываний валидации полей адреса доставки.

---
*Документацию по затронутым сервисам обновили параллельно с кодом (в рамках подхода Docs-as-Code).*
