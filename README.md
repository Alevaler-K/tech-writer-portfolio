# Портфолио технического писателя

Привет! Меня зовут **Александр Косолапов**, я технический писатель с опытом работы по методологии **Docs-as-Code**. 

Моя цель — создавать понятную, структурированную и актуальную документацию, которая помогает разработчикам, тестировщикам и пользователям быстро разбираться в продуктах, а не искать ответы в чатах.

---

## 🛠 Стек и инструменты
* **Документирование и валидация API:** REST API, OpenAPI / Swagger 3.0, JSON, Postman.
* **Языки и форматы:** Markdown, YAML.
* **Диаграммы:** UML(Sequence), BPMN(бизнес-процессы).
* **Инструменты:** VS Code, Git (GitHub, GitLab), Atlassian Confluence, Atlassian Jira, PlantUML, Draw.io.
